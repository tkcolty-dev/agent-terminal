  - **Gotcha hit twice now, worth remembering**: top-level `const X = ...` in a classic (non-module) `<script>` is visible as a bare identifier to every other script on the page, but is NOT a property of `window` — so `window.Inventory`, `window.game`, `window.SaveGame` etc. are all `undefined`. Always reference these by their bare name, never `window.<name>`, in eval/devtools/other scripts. (`window.Renderer` and `window.Minecraft2D` work fine because those are explicitly assigned as `window.X = ...` inside their files.)
